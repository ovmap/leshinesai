# 项目结构定义

本项目分为两大部分：**智能体** 和 **数字空间（Dashboard）**

---

## 1. 智能体

智能体是项目的核心交互层，具象化表现为**对话窗口**。

智能体包含两个子部分：

### 1.1 智能助手

通过自然语言交互和结构化知识库，解决传统运营中**信息查找难、知识复用率低**的问题。

**核心能力：**
- 自然语言对话
- 知识库检索与问答
- 上下文记忆与理解

### 1.2 AI 大脑

运输场景中关键控制节点，结合大数据算法，将资深运营主管经验转换成多个 skill，**自动识别运营风险、并主动推送给业务管理**。

**核心能力：**
- 数据获取（从 Dashboard 数据源）
- 数据处理（算法分析）
- 结果输出（风险预警推送）

**已实现的 Skill：**

| 序号 | Skill 名称 | 说明 |
|------|-----------|------|
| 1 | ISG订单预警流程 | 监控ISG订单异常，提前预警 |
| 2 | 签收异常超期预警 | 识别签收异常和超期情况 |
| 3 | CDD预警流程 | CDD相关风险预警 |
| 4 | 供应商全流程管理 | 供应商全生命周期管理 |

**数据流：**
```
Dashboard 数据源 → AI大脑（数据获取 → 数据处理 → 结果输出）→ 智能体对话窗口推送
```

---

## 2. 数字空间（Dashboard）

数字空间是项目的数据可视化与工作台层，由 Dashboard 中的各类组件构成。

数字空间包含三个子部分：

### 2.1 数据图表组件

Dashboard 中各类数据可视化模块，包括：

- **货量相关**：累计货量、货量趋势、货量占比
- **交付相关**：准时交付率、提货及时率、签收信息
- **异常监控**：运输异常、加急&重点客户风险、重大活动&极端天气影响
- **KPI评分**：ToB物流商、运输物流商、城配物流商、ToC物流商等多维度评分
- **成本相关**：能源价格、干单价、配单价
- **其他**：运力池、返单进展、应签未签等

### 2.2 空间与权限的千人千面

- **个性化配置**：个人页面通过拖拉拽简单操作实现个人页面配置
- **一站式个性化办公空间**
- **跨系统数据集成**
- **跨系统审批集成**

### 2.3 工作待办集成

- **日常审批**：一站式审批入口
- **工作待办**：待办事项集中管理
- **多维度空间穿梭**：在不同视图/页面间快速切换

## 两者关系

```
┌─────────────────────────────────────────────────────────────┐
│                        项目整体                              │
├─────────────────────────┬───────────────────────────────────┤
│       智能体             │         数字空间 (Dashboard)        │
├─────────────────────────┼───────────────────────────────────┤
│  ┌───────────────────┐  │  ┌─────────────────────────────┐  │
│  │   智能助手         │  │  │   数据图表组件               │  │
│  │  (自然语言交互)    │  │  │  (货量/交付/异常/KPI/成本)   │  │
│  └───────────────────┘  │  └─────────────────────────────┘  │
│  ┌───────────────────┐  │  ┌─────────────────────────────┐  │
│  │   AI 大脑          │◄─┼──│   数据源                    │  │
│  │  (风险识别/推送)   │  │  │                             │  │
│  │  - ISG预警         │  │  └─────────────────────────────┘  │
│  │  - 签收异常预警    │  │  ┌─────────────────────────────┐  │
│  │  - CDD预警         │  │  │   千人千面配置               │  │
│  │  - 供应商管理      │  │  │   工作待办集成               │  │
│  └───────────────────┘  │  └─────────────────────────────┘  │
├─────────────────────────┴───────────────────────────────────┤
│                    智能体 ↔ 数字空间 联动                      │
│         智能体可通过指令控制数字空间（如"打开货量看板"）          │
└─────────────────────────────────────────────────────────────┘
```
