# 项目结构定义

本项目分为两大部分：**智能体** 和 **数字空间（Dashboard）**

---

## 1. 智能体

智能体是项目的核心交互层，具象化表现为**对话窗口**。

智能体包含两个子部分：

### 1.1 智能助手

通过自然语言交互和结构化知识库，解决传统运营中**信息查找难、知识复用率低**的问题。

**核心能力：**
- 自然语言对话
- 知识库检索与问答
- 上下文记忆与理解

### 1.2 AI 大脑

运输场景中关键控制节点，结合大数据算法，将资深运营主管经验转换成多个 skill，**自动识别运营风险、并主动推送给业务管理**。

**核心产出：**

| 序号 | 产出名称 | 说明 | 获取方式 |
|------|---------|------|---------|
| 1 | CDD周报 | 运输准时交付率报告，包含指标定义、达成情况表、各维度分析 | `dashboard_command({ command: "data", args: { module: "cddWeeklyReport" } })` |
| 2 | PFP考核 | 物流商考核邮件内容，包含物流商平均成绩、排名、考核评级、奖惩等 | `dashboard_command({ command: "data", args: { module: "pfpAssessment" } })` |
| 3 | ISG订单预警 | 监控ISG订单异常，包含延误(delay)、在途(inTransit)、交付(delivery)三类预警 | `dashboard_command({ command: "data", args: { module: "isgAlert" } })` |
| 4 | 签收异常预警 | 识别签收异常和超期情况，提前预警 | `dashboard_command({ command: "data", args: { module: "signingAlert" } })` |

> 以上 4 项数据均在打开智能体中心页面后自动获取，推送到 dataStore，可通过 `data` 命令直接获取。

**图文展示工具：**

通过 `show_visual` 工具在聊天界面展示预制的可视化卡片，配合语音讲解使用。

| 卡片ID | 说明 |
|--------|------|
| supplier-assessment-flow | 供应商考核全流程可视化（10号初版→15号确认版→18号终版） |

**数据流：**
```
数字空间数据源 → AI大脑（智能评估）→ CDD周报 / PFP考核
                                        ↓
                              智能体对话窗口推送给用户
                                        ↓
                              show_visual 图文卡片辅助讲解
```

## 2. 数字空间（Dashboard）

数字空间是项目的数据可视化与工作台层，由 Dashboard 中的各类组件构成。

数字空间包含三个子部分：

### 2.1 数据图表组件

Dashboard 中各类数据可视化模块，按页面组织：

| 页面标识 | 页面标题 | 包含模块 |
|---------|---------|---------|
| cargoBanner | 智能体中心 | 累计货量、提货及时率、准时交付率、货量趋势、签收信息、返单进展、能源价格、干单价、配单价、运输异常、运力池、加急&重点客户风险、重大活动&极端天气影响 |
| mapPage | 地图 | 地图组件 |
| reorderDashboard | 返单看板 | 应签未签、应签未签明细、返单及时率、未返单明细 |
| cargoDashboard | 货量看板 | 货量趋势、货量占比、货量表格占比、运输异常 |
| onTimeDelivery | 准时交付率 | 准时交付率(仓+物流)、准时交付率(时间维度) |
| onTimeDeliveryCustomer | 准时交付率(联想客户) | 准时交付率(联想客户)、准时交付率(非联想客户) |
| pfpKpiWarehouse | ToB物流商KPI评分 | ToB物流商KPI评分、ToB物流商KPI排名 |
| pfpKpiTransport | 运输物流商KPI评分 | 运输物流商KPI评分、运输物流商KPI排名 |
| pfpKpiCityDelivery | 城配物流商KPI评分 | 城配物流商KPI评分、城配物流商KPI排名 |
| pfpKpiCustomer | PFP KPI-客户 | 华星物流商KPI评分、运输仓储多业务KPI评分 |
| pfpKpiToC | PFP KPI-ToC | 运输DOA KPI评分、ToC物流商KPI评分 |
| pfpKpiExpress | PFP KPI-运输快递业务 | 运输开放业务KPI评分、运输快递KPI评分 |

### 2.2 空间与权限的千人千面

支持个人页面拖拉拽配置、跨系统数据集成与审批集成。

### 2.3 工作待办集成

日常审批、工作待办一站式管理，支持多维度空间穿梭。

## 两者关系

```
┌─────────────────────────────────────────────────────────────────────────┐
│                              项目整体                                    │
├───────────────────────────────────┬─────────────────────────────────────┤
│            智能体                  │         数字空间 (Dashboard)          │
├───────────────────────────────────┼─────────────────────────────────────┤
│  ┌─────────────────────────────┐  │  ┌───────────────────────────────┐  │
│  │        智能助手               │  │  │   数据图表组件 (12个页面)       │  │
│  │   (自然语言交互/知识库)       │  │  │   千人千面 / 工作待办           │  │
│  └─────────────────────────────┘  │  └───────────────────────────────┘  │
│  ┌─────────────────────────────┐  │                                     │
│  │        AI 大脑                │  │                                     │
│  │   CDD周报 / PFP考核           │  │                                     │
│  └─────────────────────────────┘  │                                     │
├───────────────────────────────────┴─────────────────────────────────────┤
│                          智能体 → 数字空间 联动                           │
│                                                                         │
│   dashboard_command CLI 工具：                                           │
│   ┌─────────┬─────────┬─────────┬─────────┬─────────┬─────────┬──────┐ │
│   │  show   │  data   │ filter  │ action  │ layout  │  page   │ ...  │ │
│   │ 打开看板 │ 获取数据 │ 筛选条件 │ 触发操作 │ 切换布局 │ 切换页面 │      │ │
│   └─────────┴─────────┴─────────┴─────────┴─────────┴─────────┴──────┘ │
│                                                                         │
│   show_visual 工具：展示图文卡片（如供应商考核流程），配合语音讲解          │
└─────────────────────────────────────────────────────────────────────────┘
```
